# Веб-интерфейс

## Для каких текстов

Правила применяются к инструкциям и справочным материалам, в которых упоминаются элементы сайта.

## Действия пользователя

Используйте глаголы, соответствующие действиям в веб-интерфейсе: «нажмите», «кликните», «наведите курсор», «перейдите по ссылке», «выберите из выпадающего списка».

## Названия элементов

Названия кнопок, вкладок и разделов выделяйте **полужирным начертанием** и приводите точно так, как они написаны на сайте.

## Ссылки

Встраивайте ссылку в текст, который описывает ее назначение. Не используйте фразы «нажмите сюда» и «ссылка».

**Неправильно:** `Чтобы прочитать правила, кликните сюда.`

**Правильно:** `Ознакомьтесь с [правилами провоза багажа](URL).`
