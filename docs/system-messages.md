# Системные сообщения

## Для каких текстов

Правила применяются к сообщениям об ошибках, в том числе к ошибкам валидации форм.

## Ошибки

- Не обвиняйте клиента и не описывайте ошибку как его личную неудачу.
- Кратко объясните, что произошло.
- Предложите конкретный способ исправить ситуацию.

**Неправильно:** Вы ввели неправильный код бронирования!

**Правильно:** Код бронирования не найден. Проверьте правильность ввода.

## Проверка

Проверьте, что сообщение не содержит обвинений и подсказывает клиенту следующий шаг.
