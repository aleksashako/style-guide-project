# Терминология и форматы

## Для каких текстов

Правила применяются к инструкциям, справочным статьям и FAQ сайта.

## Терминология

- Используйте термин «ручная кладь» для вещей, которые клиент берет с собой в салон.
- Используйте термин «багаж» для вещей, которые клиент сдает на стойке регистрации.
- Используйте слово «клиент» вместо слова «пассажир».
- Используйте слово «бронирование» вместо слов «заказ» или «билет», когда речь идет о бронировании.

## Форматы данных

- Даты записывайте в формате `ДД.ММ.ГГГГ`, например `15.05.2026`.
- Время указывайте в 24-часовом формате, например `14:30`.
- Цены записывайте с разделителем разрядов и символом рубля: `1 500 ₽`.
- Габариты записывайте через латинскую букву `x` без пробелов, например `36x30x27 см`.

## Проверка

Перед публикацией проверьте, что термины и форматы во всех разделах документа единообразны.
