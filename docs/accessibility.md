# Правила доступности текста (Accessibility)

Для обеспечения доступности веб-сайта «Победы» для всех категорий пользователей:
1. **Альтернативный текст (alt-text):** Все изображения, иллюстрирующие габариты багажа или схемы салона, должны сопровождаться описательным `alt`-текстом.
2. **Контрастность:** При выделении предупреждений о штрафах не полагайтесь только на цвет. Обязательно используйте текстовые маркеры (**Важно**, **Внимание**).
3. **Понятность ссылок:** Текст ссылки должен быть осмысленным в отрыве от контекста. Не используйте фразы «кликните здесь».
