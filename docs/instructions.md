# Инструкции

## Для каких текстов

Правила применяются к пошаговым пользовательским инструкциям.

## Структура шагов

- Оформляйте алгоритмы нумерованными списками.
- Один шаг должен описывать одно действие.
- Начинайте каждый шаг с активного глагола в повелительном наклонении: «Откройте», «Введите», «Нажмите».
- Начинайте шаг с заглавной буквы и завершайте точкой.
- Если у действия есть условие, указывайте его после основного действия.

**Неправильно:** Если вам нужен чек, поставьте галочку.

**Правильно:** Поставьте галочку, если вам нужен чек.

Для списков перечислений используйте строчную букву в начале пункта и не ставьте знак препинания в конце строки.

## Проверка

Убедитесь, что шаги идут в порядке выполнения, каждый шаг содержит одно действие, а действия начинаются с глагола в повелительном наклонении.
